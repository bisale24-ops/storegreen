## Three hard requirements

1. **Bob IDE must be a core component.** Any framework is allowed, but the solution has to
   *showcase Bob IDE* to be eligible for judging. Bob Shell is optional.
2. **`bob_sessions/` in the final repository.** Every participant uploads Bob IDE *task session
   summary* screenshots there: in Bob IDE chat open **Tasks**, select a task, click the task header
   to see the session consumption summary, screenshot it. PNG, named clearly, e.g.
   `khlab_task01_rule_extraction_summary.png`. One per task related to the submission.
   **Taken as we go — not at the end.** This is the deliverable people miss.
3. **Own data, clean.** No client data, no company confidential data, no personal information,
   nothing from social media. Public web data is fine where the terms allow commercial use, and we
   keep a list of every site used. Compliance is on us.
